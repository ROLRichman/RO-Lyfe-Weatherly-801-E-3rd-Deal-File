Do NOT use the $281,452.88 debt amount as the property value. It is a debt/case input.

Use the normal RO'Lyfe deal framework:
**ARV – Rehab – Closing – Holding – Selling/Exit – Financing – Contingency – Required Profit = Investor MAO**

Then separately model lender constraints:
- LTC ceiling
- ARV LTV ceiling
- Total project cost
- Borrower cash/equity

The lender may underwrite differently. The machine's lender calculation is an illustrative planning layer, not a commitment or approval.
